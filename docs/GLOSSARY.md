# Short glossary

**Repository (repo)**  
The project on GitHub that holds the website files.

**Commit**  
A saved version of your changes, with a short message describing what you did.

**Branch**  
A line of history (for example `master` or `main`). Netlify usually deploys one chosen branch as the live site.

**Pull request**  
A proposal to merge changes, often used when someone should review before the live site updates.

**Netlify**  
The hosting service that turns the GitHub files into the public website and runs each **deploy** when you push or merge.

**Deploy**  
One publish cycle: Netlify takes the latest files and updates the live site (or a preview).
